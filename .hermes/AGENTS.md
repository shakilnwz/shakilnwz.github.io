# Project Skills

This site has the following Anthropic skills available in `.hermes/skills/`:

## Frontend & Design
- **frontend-design** -- Design guidance for distinctive UI; warns against AI-generated clichés (cream+terracotta defaults, SaaS-card kits, ALL-CAPS eyebrows).
- **canvas-design** -- Create poster/art PDFs and PNGs via design philosophy → canvas expression.
- **algorithmic-art** -- Generative art with p5.js, seeded randomness, interactive viewers.
- **theme-factory** -- 10 pre-set color/font themes (Ocean Depths, Sunset Boulevard, etc.) applicable to any artifact.
- **brand-guidelines** -- Brand consistency guidance.

## Testing & Build
- **webapp-testing** -- Browser automation scripts for testing web apps.
- **web-artifacts-builder** -- React + Tailwind + shadcn/ui artifact scaffolding and bundling.

These skills are loaded automatically when working within this project directory.
